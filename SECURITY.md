# Security

Report a vulnerability by
[opening an issue](https://github.com/szymonmichalik/zerobyte-relay/issues/new)
in this repository. If the details would let someone attack existing users
before a fix is out, use "Report a vulnerability" under the Security tab
instead: the report stays private until the fix is published.

I acknowledge reports within three working days and publish a fix and an
advisory once users can update. Include the version, what you did, and what
you saw.

In scope: the relay server, the protocol, and the SDKs. Out of scope: the
security of a relay you host yourself beyond this code (its TLS, OS and
network).
